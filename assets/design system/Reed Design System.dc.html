Reed — Design System

Reed

A design system for Reed's own surfaces — documentation, CLI output, and any interface the engine presents. Built on Broadsheet's newsprint foundation, tuned to Reed's identity as the thing that keeps many separate threads of state aligned and synchronized.

01 · Mark

The mark is a reed: a frame holding a row of evenly spaced teeth, the way a loom's reed holds its warp threads apart and in tension. There are exactly six teeth, one per design principle, in the same order as the deck and document — count them left to right and they spell out State-oriented, Declarative, Incremental, Event-driven, Strongly typed, Layered. Two pick up color: Declarative and Event-driven, because together they are Reed's one-sentence pitch — dependencies are declared, propagation fires on events — everything else is how that promise gets kept. Hover a tooth (or read the SVG source) and it names itself; the mark carries the whole model, not just a shape. It never appears smaller than 32px or in any color combination outside the ones below.

02 · Color

Reed inherits Broadsheet's ground and ramps rather than introducing new hues. Cyan is Reed's primary — every interactive element, link and the mark's default accent tooth. Magenta is reserved for the rarer second signal: a warning-adjacent state, or a highlight that must read as distinct from ordinary interactivity. The two never share one small component.

03 · Type

Aa Reed Source Serif 4 carries both headings and body text, at the body weight's true italic for emphasis and pull quotes — never a synthesized slant. One face, doing every job, is the same discipline the mark keeps: few elements, used deliberately.

04 · Iconography

Interface icons stay on Broadsheet's own set — Phosphor, duotone weight. Reed adds four concept marks, in the same two-tone stroke language as the logomark, for the ideas its own documentation returns to.

06 · Usage

Do

  • Use cyan for anything a user can act on.
  • Keep the mark's frame and outer teeth in plain ink; color only the two marked teeth.
  • Let whitespace separate sections — no boxes except the one applied card above.

Don't

  • Recolor the mark, stretch it, or drop a tooth.
  • Pair cyan and magenta in the same small component.
  • Introduce a second typeface for code or UI chrome — set code in the same serif's monospace fallback shown above, sparingly.
