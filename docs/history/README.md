# Historical design records

These documents were written during the issue #4 refactor (Flow
composition, Session, NodeContext, ArtifactRecord) and were removed from
`docs/` when it finished. They are restored here, unchanged, because the
source code still cites them as the origin of its design decisions.

They describe the system as it was being built: names such as `Run`,
`publish()`, `Parcel` and `Depot` belong to earlier stages and are no
longer part of Reed's API. The current documentation is in
`docs/refactor/` and in the module docstrings.
